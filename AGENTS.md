# Repository Instructions

## Git remotes

This repository is mirrored to two remotes:

- `origin`: `https://github.com/xuwenqing2014/AI-Tools.git`
- `codeberg`: `https://codeberg.org/mintnow/AI-Tools.git`

Whenever a change is committed and the user asks to push it, push the same branch to both remotes. Verify that both pushes succeed. Do not remove, rename, or overwrite either remote without explicit user approval.

Typical push commands:

```bash
git push origin <branch>
git push codeberg <branch>
```
